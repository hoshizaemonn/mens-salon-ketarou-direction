PATTERN 01 / 既存の毛太郎

「予約する場所、間違えてる」篇

恋愛だけ、三歩先。 既存の毛太郎とツルツルの相棒を使用。本人は真剣、相棒は冷静。その温度差で笑わせます。

相談 → 結婚式を予約 → 新婚旅行も予約 → 身だしなみ → 早すぎる誓い
セリフ・秒数・演出指示を読む（A01〜A06）
A010–5秒

モテたい男の相談

毛太郎「モテたい。まず予約だよな？」 相棒「お、わかってるね」

ビーチの二人。毛太郎だけ前のめり。

A025–10秒

予約したのは、結婚式場

毛太郎「結婚式場、押さえた」 相棒「脱毛の予約だよ。何人飛ばした？」

妄想の鐘を鳴らし、ツッコミで現実へ戻す。

A0310–15秒

相手の席だけ、空いている

毛太郎「新婚旅行も、二人分」 相棒「相手は？」 毛太郎「そこだけ空いてる」

二つの旅行かばん。空席を見せて一拍。

A0415–21秒

まずは、自分を整える

相棒「まず、自分を整えよう。毛太郎で」

一緒に歩き出す。日を改め、身だしなみを整えた姿へ。

A0521–28秒

声をかけられた瞬間に

女性「すみません」 毛太郎「誓います！」 女性「駅、どっちですか？」 相棒「まだ道聞かれただけ」

姿勢を正す毛太郎。女性の冷静な返答で落とす。

A0628–33秒

照れ笑いから、ブランドへ

ナレ「脱毛は、都度払いで気軽に。」 ジングル「メンズサロン、けたろう♪」

笑いの余韻を残し、ロゴ → 提供CTA動画へ。

PATTERN 02 / 海のモズク

「モズクじゃない、本人です」篇

モズクに見えたのは、頭の毛。 冒頭は海面に漂う頭の毛だけ。引くと人間くさい顔と、腕・脚・胴まで濃い毛に覆われた全身が見える。岸の相棒との真顔の掛け合いへつなげます。

頭の毛だけ → 引いて正体が分かる → 海で出会い待ち → 上陸 → 自分と場所を変える
セリフ・秒数・演出指示を読む（B01〜B06）
B010–4秒

モズクに見える

セリフなし。波の音。

海面の毛だけを寄りで見せる。顔・目・体を隠し、モズクに見える状態を保つ。

B024–9秒

引くと、本人

相棒「モズクかと思った」 主人公「……俺です」

カメラを引く。毛が頭につながり、水中の毛むくじゃらの腕・脚・胴まで見える。相棒は岸にいる。

B039–14秒

海で待つな

主人公「いい出会い、待ってる」 相棒「そこで？」

本人は真顔。岸との距離、波の音、短い間で笑わせる。

B0414–21秒

まず陸へ

主人公「モテたいんだよ」 相棒「まず陸、上がれ。それから毛太郎」

岩場へ上がるぎこちない動き。肩・胸・腕・脚まで長い毛が密生した姿を、全身でしっかり見せる。

B0521–28秒

場所も変えよう

主人公「どう？ モテそう？」 相棒「まず、人のいるとこ行こう」

後日の脱毛後イメージ。同じ顔・体格のまま、腕・脚・首元の濃い毛がなくなった肌を見せる。白いノースリーブと短パン。まだ人気のない岸にいるのがオチ。

B0628–33秒

清潔感で締める

ナレ「脱毛は、都度払いで気軽に。」 ジングル「メンズサロン、けたろう♪」

二人で歩き出す。明るい白地のロゴ画面 → 提供CTA動画へ。

PATTERN 03 / 動物系キモカワ

「モテ期、待ってます」篇

待っているだけの男が、動き出す。 全身が濃い毛で覆われた、細長い体と人間くさい顔の架空の獣。ぼやきで笑わせ、最後は同じ顔のまま腕・脚の毛がなくなった肌へ。落ち着いた手描き調と、脱毛前後のはっきりした差を両立します。

見た目の違和感 → モテ期を待つ → ツッコミ → 行動 → 自分に好感
セリフ・秒数・演出指示を読む（C01〜C06）
C010–4秒

妙に人間くさい、謎の獣

主人公「……モテ期、遅いな」

木陰でだらっと座る。肩・胸・腕・脚まで毛むくじゃら。ゆっくりこちらを見る。

C024–9秒

来る約束、してた？

相棒「待ち合わせ？」 主人公「モテ期と」 相棒「来るって言ってた？」

見た目の奇妙さに対し、会話は日常的に。

C039–14秒

連絡先も、知らなかった

主人公「……連絡先、知らない」 相棒「じゃあ待つなよ」

一拍だけ無音。風が毛先を揺らす。

C0414–19秒

待つのをやめる

相棒「まず、自分から変えてみたら？」 主人公「毛太郎、行くか」

まだ全身毛むくじゃらの姿で立ち上がる。毛太郎での脱毛に向かう行動につなげる。

C0519–28秒

最初の一人は、自分

主人公「……こいつ、いいじゃん」 相棒「お前だよ」 主人公「まず、一人に好かれた」 相棒「自分だけどな」

後日の脱毛後イメージ。毛深かった腕・首元が滑らかな同じ獣。鏡の自分にも同じ変化を反映し、ノースリーブで見せる。

C0628–33秒

愛着を残して、きれいに締める

ナレ「脱毛は、都度払いで気軽に。」 ジングル「メンズサロン、けたろう♪」

毛のなくなった腕と脚が見える姿 → 明るい白いロゴ画面 → 提供CTA動画へ。顔・体格は維持する。

3案に共通する広告の着地

「モテたい」→ 笑える空回り → 自分を整える → 毛太郎。
説明テロップは使わず、セリフで進行。冒頭から右上にロゴを表示し、最後は店名とジングル、提供CTA動画へつなぎます。

変化は「日を改めた場面」として表現。一度で仕上がる描写にはせず、②③は同じキャラの全身の濃い毛と、その後の滑らかな腕・脚の差を見せます。服だけの変化にせず、肌が見える構図と明るい背景で清潔感を出します。実際の店舗内装は描きません。

毛太郎の修正方向を、3パターンの構成台本と図解に整理しました。①は既存キャラの掛け合い、②はクライアント様からいただいた海のモズクの導入を、実は頭の毛だったという見せ方に変更した案、③は動物系キモカワのぼやきです。「モテたい」という動機は共通で残し、②③は全身毛むくじゃらの姿から、同じキャラの腕・脚の毛がなくなった姿へ変化させ、脱毛と清潔感が伝わる広告として締めます。
